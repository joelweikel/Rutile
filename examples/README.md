# Al–Cu equilibrium example

[`AlCu-21Kro.tdb`](AlCu-21Kro.tdb) encodes the binary Al–Cu thermodynamic reassessment by A. Kroupa, O. Zobac, and K. W. Richter, *Journal of Materials Science* 56 (2021), 3430–3443. It includes liquid, solid solutions, and intermetallic phases. [Original assessment](https://doi.org/10.1007/s10853-020-05423-7)

Bengt Hallstedt prepared the TDB for the SGTE binary collection. Rutile includes an unmodified copy under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The SHA-256 is `bd06016e51db2bef626a65b9f3a00b660e9b1c8a7c8c10e4d0ad8867809c62e4`. [SGTE collection publication](https://doi.org/10.1016/j.calphad.2025.102833)

See the [project README](../README.md#try-the-included-example) for the browser walkthrough.
